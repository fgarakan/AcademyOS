## Recommended path

**Next.js 14 + Supabase** for the production application.

### Why Next.js 14
- App Router with server components = efficient data fetching from Supabase
- API routes for server-side AI calls (Claude API) without exposing keys
- Built-in deployment to Vercel
- TypeScript native
