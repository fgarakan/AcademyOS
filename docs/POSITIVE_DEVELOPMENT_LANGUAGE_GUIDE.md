# Positive Development Language Guide

**Sprint:** 155
**Date:** 2026-05-01

---

## Principle

Academy OS uses positive, mission-based language in all player-facing and parent-facing UI. Language should be supportive, clear, and professional. Never use deficit or deficit-adjacent terms.

---

## Approved Terms

| Use this | Not this |
|---|---|
| Doing Well | Strengths / Good at |
| Working On | Weaknesses / Problems / Issues |
| Current Focus | Deficiencies / Gaps |
| Next Step | Needs improvement |
| Development Priority | Problems to fix |
| Coach Insight | Concerns |
| Progress Evidence | Failures / Setbacks |
| Needs Attention (director-only) | Bad performance |

---

## Parent-Facing Examples

**Progress card:**
> "Doing well: Mia is building stronger rally tolerance."
> "Working on: Her current focus is recovering after wide balls."
> "Next step: Coaches will continue using recovery games and simple reset cues."

**Coach note summary:**
> "Coach insight: Mia is responding well to point play formats."
> "Progress evidence: Completed 3 consecutive sessions with strong court positioning."

---

## Player-Facing Examples

**Progress card:**
> "Your strength: You are getting better at staying in rallies."
> "Your mission: Recover after wide balls and get ready for the next shot."
> "Next win: Reset to the middle after every crosscourt ball."

---

## Director-Facing Examples

Directors can see more direct language in internal tools (Alerts, Priority Queue), but still avoid clinical deficit language.

**Director OK:**
> "Players needing attention"
> "Missing development summary"
> "Needs review"
> "Score delta declining"

**Director avoid:**
> "Failing players"
> "Weak players"
> "Player deficiencies"

---

## Implementation Checklist

- [ ] Player profile cards: "Doing Well" section (not "Strengths" or "Good at")
- [ ] Player profile cards: "Working On" section (not "Weaknesses")
- [ ] Coach notes: surfaced as "Coach Insights" in parent view
- [ ] Dashboard priority queue: "Needs Attention" (not "Problem Players")
- [ ] Alert titles: constructive, directional (not deficit-labeling)
- [ ] Parent portal: all copy reviewed for supportive tone

---

## Language Review Process

1. When writing new UI copy, check this guide first.
2. For parent-facing text, run a tone check: would a parent feel reassured or anxious?
3. For player-facing text, run a motivation check: does this give the player a clear next action?
4. If unsure, default to the approved terms column.
