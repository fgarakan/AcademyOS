## Context from Sprint 387D audit

The 387D audit scored `AcademyDnaReviewStep` / DNA Summary at **6/10** — the lowest content score in the DNA flow. The audit described the prototype's DNA Summary screen as:

> "Left/right split layout: 300px DNA Card (left) + detail sections (right), DNA card has: academy initial monogram badge, narrative paragraph, 2×2 stat grid (Coaching Styles / Session Blocks / Dev Priorities / Parent Styles counts), academy model badge pill. Detail sections: SectionRow components with teal-tinted pills. Three action buttons: 'Approve Academy DNA' (primary) / 'Edit Selections' (ghost) / 'Adjust with DONNA' (teal-outline)"

The current `AcademyDnaSummaryCard` was a readiness bar + 4 section rows — a form-summary widget, not an identity card. It had no monogram, no narrative, and no stat grid.

---

## What changed

### `AcademyDnaSummaryCard.tsx` — non-compact variant rewritten

**Before (non-compact):**
- Readiness bar (pct of 9 fields filled)
- 4 section rows (Academy Identity / Coaching DNA / Session Structure / Parent + Player Experience) with CheckCircle2/Circle + summary text + pencil edit button
- Section rows scrollable within card

**After (non-compact — premium DNA identity card):**

#### Identity header
- Academy monogram circle (`w-11 h-11 rounded-xl bg-lime/10 border border-lime/25`):
  - 1–2 initials from `draft.academyName` (first letter of each word for 2+ word names, first 2 chars for single-word)
  - Fallback: `"?"` when name is empty
- Academy name (`text-sm font-bold text-text-primary`):
  - Fallback: `"Draft Academy DNA"`
- Academy model badge pill (`text-[10px] text-text-muted bg-surface border border-border rounded-md`):
  - Short label: Private Lessons / Group Programs / High Performance / Recreational + Development / Multi-Program / School Partnership
  - Fallback: `"Model not selected"` (italic muted)

#### DONNA narrative paragraph
Section header: `"DONNA Learned"`

Generated by `buildNarrative(draft)`:
```
"Based on your answers, DONNA sees this as a [model] environment built around [coaching styles], [session structure], [dev priorities]. This DNA will guide future curriculum suggestions, class templates, coach defaults, and parent-safe communication drafts."
```

Fallback when no data filled:
```
"Complete the earlier steps and DONNA will generate a personalized summary of your academy DNA here."
```

Uses only actual `draft` values — no fake or placeholder data fabricated.

#### 2×2 stat grid
Section header: `"Draft Summary"`

| Cell | Data source | Zero state |
|---|---|---|
| Coaching Styles | `draft.coachingStyles.length` | `—` (muted) |
| Session Blocks | `draft.sessionBlocks.length` | `—` (muted) |
| Dev Priorities | `draft.developmentPriorities.length` | `—` (muted) |
| Parent Styles | `draft.parentStyles.length` | `—` (muted) |

Numbers use `font-mono font-bold text-xl text-text-primary`. Zero values show `—` in `text-muted/30` to avoid implying fake completion.

#### Safety footer
```
"Draft only — review before saving"
```

Compact mode is used in `ActivationChecklistStep` and is unchanged in structure. Two step index bugs fixed:

| Section | Old stepIndex | New stepIndex | Why |
|---|---|---|---|
| Session Structure | 3 (Coach Communication) | 4 (Session Design) | Session blocks and dev priorities are set in steps 4–5, not step 3 |

---

### `AcademyDnaReviewStep.tsx` — 2-column responsive layout

**Before:** Single-column stacked layout:
1. `OnboardingStepHeader`
2. `AcademyDnaSummaryCard` (above detail sections)
3. Full DNA detail (DnaRow sections)
4. DONNA summary bubble
5. Navigation

**After:** Header full-width + 2-column responsive grid:
1. `OnboardingStepHeader` (full width)
2. `lg:grid lg:grid-cols-[1fr_272px] lg:gap-6 lg:items-start`
   - Right column (`order-1 lg:order-2 lg:sticky lg:top-6`): `AcademyDnaSummaryCard` — appears first on mobile (stacked above), sticky on desktop
   - Left column (`order-2 lg:order-1`): Full DNA detail sections + DONNA summary bubble + navigation

At desktop (lg breakpoint): DNA card sticky on right (272px), detail sections flexible on left.
At mobile: DNA card stacked above detail sections.

**Development Priorities DnaRow fix:** previously called `onEditStep(4)` (Session Design step). Now correctly calls `onEditStep(5)` (Player Development step).

**`updateDraft` prop:** was unused in the component. Renamed to `_updateDraft` to make the intentional non-use explicit and suppress potential linter warnings.
