## DONNA `type="honest"` Response

When DONNA cannot surface data:
- Response type is `'honest'`
- Color: orange (`#FF9500`) — visually distinct from normal response (violet)
- Label: "Not available yet"

This prevents fake certainty: if the underlying data is not accessible, DONNA signals this clearly rather than inventing an answer.
