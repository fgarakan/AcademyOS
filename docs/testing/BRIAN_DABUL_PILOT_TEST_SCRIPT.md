# AcademyOS — Pilot Test Script for Brian

Hi Brian — this is a simple walkthrough to try AcademyOS the way you'd use it day to day. No technical knowledge needed. Just follow each step and jot a quick note if anything feels confusing or doesn't work.

**Tips:**
- Anywhere you see the **DONNA** button, you can tap it and just talk or type naturally — like "What should I do today?" or "Walk me through this."
- Nothing you do here sends real messages or makes permanent changes without you approving it first.
- If a step doesn't work, write one line about what happened and move on.

---

### 1. Start your morning
- Open AcademyOS. Tap **DONNA** and say: **"Good morning."**
- Then ask: **"What should I do today?"**
- 👉 DONNA should tell you the top thing that matters, why, and offer to take you there.

### 2. Set up your academy
- Go to **Onboarding**.
- Pick how you want to set up, tap **Begin**, and answer the questions.
- 👉 Your answers should be saved as you go.
- Worked? ☐ Yes ☐ No — Notes: ______________________

### 3. Build a bit of curriculum
- Go to **Curriculum → Builder**.
- Add or change something small.
- 👉 It should be saved as a **draft for your approval** — not changed immediately.
- Worked? ☐ Yes ☐ No — Notes: ______________________

### 4. Create a class template
- Go to **Templates → New class template** and finish the short wizard.
- 👉 It should save as a draft.
- Worked? ☐ Yes ☐ No — Notes: ______________________

### 5. Create a session
- Go to **Sessions → New Session**. Choose a template, a coach, and a date. Tap **Create**.
- 👉 The session should be created and open up.
- Worked? ☐ Yes ☐ No — Notes: ______________________

### 6. Assign a coach
- During the step above (or in Onboarding → Coaches), pick the coach for the group.
- 👉 The coach should be saved and selectable.
- Worked? ☐ Yes ☐ No — Notes: ______________________

### 7. Do a coach wrap-up (as a coach)
- Open a session as a coach and tap **Start Wrap-Up**.
- Answer the six quick questions (you can talk instead of typing). Tap **Submit for Review**.
- 👉 You should see "submitted for review" — nothing is sent to anyone yet.
- Worked? ☐ Yes ☐ No — Notes: ______________________

### 8. Assess a player
- Open a player's profile and do a quick assessment.
- 👉 It should save. No player should move levels automatically.
- Worked? ☐ Yes ☐ No — Notes: ______________________

### 9. Place a player
- Go to **Placement**. For a new player: create a recommendation, approve it, then activate.
- 👉 You should see a clear "this is final" message before activating.
- Worked? ☐ Yes ☐ No — Notes: ______________________

### 10. Parent view + a parent update
- Open a player profile and tap **Initiate Parent Update**.
- 👉 It should create a draft for you to review — it does NOT send to the family.
- Then open the **Parent** view to see what a parent sees, and tap **Ask DONNA**.
- Worked? ☐ Yes ☐ No — Notes: ______________________

### 11. Approve things
- Go to **Approvals**. Open a pending item and **Approve** or **Reject**.
- 👉 Only after you approve does anything actually happen.
- Worked? ☐ Yes ☐ No — Notes: ______________________

### 12. Talk to DONNA anywhere
- On any screen, tap **DONNA** and try: **"What should I do here?"**, **"Walk me through this."**, **"Take me to completion."**, **"What's next?"**
- 👉 DONNA should give a clear, specific answer and a next step — never ask you to figure it out yourself.
- Worked? ☐ Yes ☐ No — Notes: ______________________
